# 🚚 Linear Regression - Delivery Time Prediction

This project focuses on predicting delivery time using the **Linear Regression** algorithm. The objective is to build a regression model that estimates delivery time based on available input features and evaluates its performance using standard regression metrics.

---

## 📌 Project Overview

Delivery time prediction is an important problem in logistics and supply chain management. Accurate predictions help businesses improve customer satisfaction, optimize delivery routes, and manage operational efficiency.

In this project, a Linear Regression model is developed following the complete machine learning workflow, including data preprocessing, exploratory data analysis, model training, and performance evaluation.

---

## 🎯 Objectives

- Understand the relationship between delivery time and input features.
- Perform exploratory data analysis (EDA).
- Clean and preprocess the dataset.
- Build a Linear Regression model.
- Evaluate the model using regression metrics.
- Interpret the results and identify areas for improvement.
